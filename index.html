Dispatch

How I keep all my agents organised. Every Claude Code session becomes a little Bia, a pixel-art mini me in a bakery, so one look tells me which agents are baking, which need me, which are done and which fell asleep. It shows each agent's history and what it's asking me, rings a bakery sound when something changes and keeps my PR review queue alongside.
